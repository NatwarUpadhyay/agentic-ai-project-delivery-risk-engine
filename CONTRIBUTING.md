# Contributing

Thanks for your interest in improving this project. Contributions are welcome and focused on documentation, diagrams, and example scenarios.

## How to Contribute
1. Open an issue describing the change or improvement.
2. For documentation updates, propose clear edits with rationale.
3. Keep language professional and aligned to project delivery and governance standards.

## Content Guidelines
- Use clear, structured Markdown.
- Prefer ASCII characters for portability.
- Avoid sensitive or client-identifying data in examples.
- Keep diagrams consistent with the six-agent architecture.

## Submitting Changes
- Fork the repo or create a branch.
- Make focused edits with descriptive commit messages.
- Open a pull request referencing the related issue.
